# Tall Grass Privacy Policy

Public privacy policy for the Android and iOS versions of **Tall Grass** by
Dragon Pixel Studio.

- Published URL: <https://dragonpixelstudio.github.io/tallgrass-privacy/>
- Web page: [`index.html`](./index.html)
- Store-specific working notes: [Google Play](./google-play-privacy-policy.md) and
  [Apple App Store](./apple-app-privacy-policy.md)

The public page covers local game saves, Google Mobile Ads and consent controls,
Google Play Games Services on Android, app-store services, and user choices.
